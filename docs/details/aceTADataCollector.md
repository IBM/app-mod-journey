# Using the ACE Application Modernization Accelerator Data Collector

 - The [ACE](https://www.ibm.com/docs/en/app-connect) product has its own Data Collector to accelerate modernization
 - The results for the ACE TADataCollector can be uploaded and viewed in Application Modernization Accelerator
 - This Data Collector comes as part of ACE (Note: It **can not** be downloaded from Application Modernization Accelerator)
 - Full details on how to use ACE TADatCollector can be found [here](https://www.ibm.com/docs/en/app-connect/12.0?topic=administration-tadatacollector-command)
